Gated decode — lexicographic ordering

Hard constraints decide what is possible. Scoring only ranks what survives. Nothing is added together.

hard gate — deterministic, no score soft evidence — only ranks survivors human decision
0 · intake
Form version, page completeness
pages received = pages expected for this revision
A 4-page legacy fax is not a truncation. Version first, then everything else.
▾
1 · geometry
Normalize the page
deskew → perspective warp → crop to form frame → canonical canvas
Template boxes become stable, so fields are found by position — no model reads the page to locate them.
▾
2 · hard set
Build the admissible set A
A = leaves(code_set) ∩ indications(drug) ∩ grammar(form version)
Empty A → CLINICAL_CHECK_UNAVAILABLE. Do not reject the document; the map is incomplete.
▾
3 · enumerate
Generate candidate readings
segmentation choices × per-glyph alternatives (bounded)
Includes the leading-letter class — a digit-only alphabet cannot reach a letter-first code.
▾
4 · gate
Filter — order matters, no scores here
(a) exists in code_set  →  (b) ∈ A
A confidence score may never promote a code that fails (a) or (b). This is the rule my first build broke.
▾
5 · rank
Score only the survivors
shape score → margin between top two distinct readings
Margin is compared to calibrated thresholds. It is evidence, not probability.
▾
6 · decide
Map to exactly one disposition
margin ≥ τ_high → accept  ·  τ_low ≤ margin < τ_high → review
Reason codes — the audit trail is this line
MATCH_INDICATIONsurvivors exist, margin clear → accept
AMBIGUOUS_SHAPEsurvivors exist, margin below τ_low → human picks top 2
CLINICAL_MISMATCHreal code, but not an indication for this drug → callback
NO_VALID_CODEnothing parsed exists in the code set → callback
CLINICAL_CHECK_UNAVAILABLEA empty — map gap, not a document defect
Logged with every decision: source hash · crop box · preprocessing params · chosen split count · per-glyph bbox + alternatives + scores · code_set fiscal-year version · indication_map · rule_set · thresholds · margin · reason code · any human override. Same inputs + same versions must replay to the identical output.
