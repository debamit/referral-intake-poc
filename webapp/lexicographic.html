Lexicographic ordering

How a referral field is decoded when the value space can be constrained — and why the ordering matters more than the accuracy of any single step.

Hard constraints decide what is possible. Scoring only ranks what survives. The two are never added together. A confidence score may not promote a value that fails a gate, however strongly the glyphs appear to match it.

The order

2 · hard set
Build the admissible set
A = leaves(code_set) ∩ indications(drug) ∩ grammar(form revision)
This is the drug doing the work. An adalimumab referral can only carry a few hundred codes, not seventy-odd thousand. If A is empty, the map is incomplete — that is a data gap, not a document defect.
▾
4 · gate
Filter, in order, with no scores
(a) exists in code_set  →  (b) member of A
Existence kills pseudo-codes that look plausible; membership kills real codes prescribed for the wrong disease. Both are deterministic and replayable.
▾
5 · rank
Score only the survivors
shape score → margin between the top two distinct survivors
Confidence enters here and nowhere earlier. The margin is compared to calibrated thresholds; it is evidence, not probability.
▾
6 · decide
One disposition, one reason code
margin ≥ τ_high → accept · τ_low ≤ margin < τ_high → human review
The reason code is the audit trail. "Why was this classified as psoriasis" has a one-line answer, reproducible from the log.

Why not a single weighted score

An early build of this scored candidacy as a +2.5 bonus and shape as 0.0–1.0, then took the maximum. It reported a margin of 2.47 that was almost entirely bonus, and it promoted a reading with a worse shape score because the bonus outweighed the difference. A weighted sum cannot answer "why this one", because the answer is "two numbers were added." Lexicographic ordering can: it was the only reading that both exists and is indicated; among those, it had the best shape score.

What makes it auditable

Every decision logs its inputs and its versions: source hash, crop box, preprocessing parameters, the split count chosen, each glyph's bounding box with its alternatives and scores, the code_set fiscal-year version, the indication_map, the rule_set, the thresholds, the surviving readings, the margin, the reason code, and any human override with who and when.

Same inputs and same versions must replay to the identical output. That property — not accuracy — is what separates this from adjusting a prompt and hoping. And when the code set updates on 1 October, historical decisions replay against the version that made them, so an old answer does not silently change.
